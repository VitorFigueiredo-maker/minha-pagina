# Minha página

Minha primeira página publicada na internet: um projeto simples para praticar desenvolvimento web e experimentar ideias visuais.

**Acesse o site:** [vitorfigueiredo-maker.github.io/minha-pagina](https://vitorfigueiredo-maker.github.io/minha-pagina/)

## Sobre o projeto

A página apresenta uma luminária feita com CSS. O botão alterna entre os temas escuro e claro e atualiza o estado da luz na tela.

## Tecnologias

- HTML
- CSS responsivo
- JavaScript

## Executar localmente

1. Clone este repositório:

   ```bash
   git clone https://github.com/VitorFigueiredo-maker/minha-pagina.git
   ```
2. Abra a pasta e carregue o arquivo `index.html` no navegador. Não é necessário instalar dependências.

## Publicação

O site é publicado pelo GitHub Pages a partir da branch `main`.
